This edition incorporates the ones we play from the Ukulele Wednesdays songbook with our own (first edition) songbook. It’s quite long as a result, but the idea is that we do one big print then add new songs in alphabetical order. Alternatively, more of us are using tablets these days. Alternatively Alternatively we could have a collection (ie a collection for money!) and get a whole bundle printed off. 

Can everyone (who cares) let me know if there are any favourites missed. In particular, are there any songs from the big (ukulele wednesdays) songbook which you think should be on the list?
